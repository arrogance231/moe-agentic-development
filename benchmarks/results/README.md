# benchmarks/results

Aggregated results and analysis reports produced by the `moe-benchmarking`
skill, following `skills/moe-benchmarking/examples/benchmark-protocol.md`.

Contains the four-arm results table (A0 bare / A1 search / A2 skills / A3
skills+search, per task and metric), the statistical analysis — primary endpoint
A3 vs A1, secondaries Holm-corrected — and the final benchmark report.

Every report states the retrieval-only gain (A1 - A0) before stating the skill
effect, so readers can see how much of the difference plain search already buys.
